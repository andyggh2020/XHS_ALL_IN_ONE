## 1. 快速启动

### 本地开发模式

```bash
# 克隆项目后，安装 Python 依赖
pip install -r requirements.txt

# 安装前端依赖（首次）
cd frontend && npm install && cd ..

# 一键启动后端 + 前端
python main.py --with-frontend
```

启动成功后：
- 前端：http://127.0.0.1:5173
- 后端 API 文档：http://127.0.0.1:8000/docs

### Docker 模式

```bash
docker-compose up -d
```

## 2. 注册与登录

### 首次使用

1. 打开 http://127.0.0.1:5173
2. 点击「注册」，填写用户名（≥3位）和密码（≥6位）
3. 注册成功后自动登录

### 提升为管理员

首个注册用户可通过以下命令提升为管理员（企业级会员）：

```bash
python -m backend.app.core.init_admin
```

### 登录说明

- 系统使用 JWT Token 鉴权，Token 有效期内无需重复登录
- 支持 Token 刷新，长时间使用不会强制退出

## 3. 模型配置（AI 功能前置）

**所有 AI 功能（改写、润色、图片生成）都依赖此配置，请优先完成。**

### 配置步骤

1. 左侧菜单 → **模型配置**
2. 点击「新增配置」
3. 填写以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| 名称 | 自定义标识 | 火山引擎-文本 |
| 类型 | `text`（文本）或 `image`（图片） | text |
| 提供商 | 服务商名称 | volcengine |
| 模型名称 | 具体模型 ID | doubao-pro-32k |
| Base URL | API 端点 | https://ark.cn-beijing.volces.com/api/v3 |
| API Key | 服务商密钥 | sk-xxxx |

4. 勾选「设为默认」
5. 点击「测试连接」验证配置是否有效

### 支持的服务商

任何兼容 OpenAI 接口格式的服务均可接入，包括：
- 火山引擎（豆包）
- 阿里云百炼（通义千问）
- DeepSeek
- OpenAI / Azure OpenAI
- 本地 Ollama

## 4. 账号矩阵

管理小红书账号，支持 **PC 端**和**创作者平台**两种类型。

### 添加账号

#### 方式一：Cookie 导入（推荐）

1. 左侧菜单 → **账号矩阵** → 「导入 Cookie」
2. 选择账号类型：
   - `pc`：用于搜索、采集数据
   - `creator`：用于发布笔记
3. 粘贴 Cookie 字符串
4. 勾选「同步 Creator 账号」可一次性同时导入 PC + Creator

**如何获取 Cookie：**
- 浏览器打开小红书，登录后按 F12 → Network → 任意请求 → Request Headers → 复制 `cookie` 字段值

#### 方式二：扫码登录 / 手机验证码

在账号矩阵页面选择对应登录方式，按提示操作。

### 账号健康巡检

- 系统每 2 小时自动检测所有账号 Cookie 是否有效
- 失效账号会标记为「已过期」并推送通知
- 手动检测：点击账号卡片右侧「检测」按钮

### 账号状态说明

| 状态 | 含义 |
|------|------|
| active | 正常可用 |
| expired | Cookie 已过期，需重新导入 |
| checking | 正在检测中 |

## 5. 笔记发现

搜索小红书全站笔记，一键保存到内容库。

### 关键词搜索

1. 左侧菜单 → **笔记发现**
2. 选择一个有效的 **PC 账号**
3. 输入关键词，设置筛选条件：
   - 排序：综合 / 最新 / 最热
   - 类型：全部 / 图文 / 视频
   - 时间范围
4. 点击搜索

### 查看笔记详情

点击任意笔记卡片，右侧抽屉展示：
- 无水印原图（可下载）
- 互动数据（点赞、收藏、评论数）
- 评论列表
- 「保存到内容库」按钮

### URL 直查

在搜索框粘贴笔记链接，直接获取该笔记详情。

## 6. 内容库

所有采集的笔记统一存储在内容库，与小红书账号解耦。

### 视图切换

- **卡片视图**：图文预览，适合浏览
- **列表视图**：紧凑展示，适合批量操作

### 筛选与搜索

- 关键词搜索（标题 + 正文）
- 标签筛选
- 平台筛选

### 标签管理

1. 选中笔记 → 「编辑标签」
2. 输入标签名，回车确认
3. 标签可在筛选栏复用

### 批量操作

勾选多条笔记后可：
- 批量打标签
- 批量导出（JSON / CSV）
- 批量删除

### 发送到草稿

点击笔记卡片上的「创建草稿」，笔记内容（标题、正文、图片）深拷贝进入草稿工坊。

## 7. 草稿工坊

三栏布局：**草稿列表 | 编辑器 | AI 助手**

### 创建草稿

- 从内容库点击「创建草稿」（推荐）
- 或在草稿工坊直接点击「新建草稿」手动填写

### 编辑内容

在中间编辑器中：
- 修改标题
- 编辑正文
- 管理标签（点击标签可删除，输入框添加新标签）
- 拖拽排序图片素材

### AI 改写

右侧 AI 助手面板：

1. **改写正文**：点击「AI 改写」，系统调用默认文本模型重写正文
2. **润色标题**：点击「润色标题」，生成更吸引人的标题
3. **生成标签**：点击「生成标签」，自动提取相关话题标签
4. **自定义指令**：在输入框填写具体要求（如"改写成口语化风格，字数控制在300字以内"）

> AI 改写需要先在「模型配置」中设置默认文本模型。

### 图片素材管理

- 拖拽调整图片顺序（影响发布时的展示顺序）
- 点击图片可预览大图
- 删除不需要的图片
- 支持 AI 图片润色（选中图片 → 「AI 润色」）

### 发送到发布中心

编辑完成后，点击「发送到发布中心」，填写：
- 选择 Creator 账号
- 发布模式：立即 / 定时
- 可见性：公开 / 私密
- 话题标签
- 地理位置（可选）

## 8. 发布中心

管理所有待发布和已发布的任务。

### 发布状态

| 状态 | 含义 |
|------|------|
| pending | 等待发布 |
| publishing | 发布中 |
| published | 已发布 |
| scheduled | 定时发布，等待触发 |
| failed | 发布失败，查看错误信息 |

### 立即发布

1. 找到目标发布任务
2. 确认账号、内容、图片无误
3. 点击「发布」
4. 等待状态变为 `published`，可点击外链查看小红书原文

### 定时发布

在草稿工坊「发送到发布中心」时选择「定时发布」，设置发布时间。

> 定时发布需要在 `config/default.yaml` 中开启调度器：
> ```yaml
> scheduler:
>   enabled: true
> ```

### 发布失败处理

1. 查看失败原因（点击任务查看 `publish_error`）
2. 常见原因：
   - Cookie 过期 → 重新导入 Creator 账号 Cookie
   - 图片上传失败 → 检查图片 URL 是否可访问
   - 内容违规 → 修改正文后重新发布
3. 修复后点击「重试」

## 9. 自动运营

配置关键词和调度规则，系统全自动完成：**搜索 → AI 改写 → 发布**。

### 创建自动任务

1. 左侧菜单 → **自动运营** → 「新建任务」
2. 填写配置：

| 字段 | 说明 |
|------|------|
| 任务名称 | 自定义标识 |
| 关键词 | 多个关键词，系统随机选取执行 |
| PC 账号 | 用于搜索笔记 |
| Creator 账号 | 用于发布笔记 |
| AI 改写指令 | 自定义改写风格，留空使用默认 |
| 调度类型 | manual / daily / weekly / interval |

### 调度类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| manual | 手动触发，不自动执行 | 按需运行 |
| daily | 每天固定时间执行 | 每天 09:00 |
| weekly | 每周指定星期执行 | 每周一、三、五 |
| interval | 按小时间隔循环执行 | 每 24 小时 |

### 手动触发

任务列表 → 点击「立即执行」，系统执行一次完整管线并返回结果。

### 执行流程

```
随机选取关键词
    ↓
搜索小红书热门笔记（按互动量排序）
    ↓
AI 改写标题 + 正文
    ↓
创建草稿 + 复制图片素材
    ↓
创建发布任务（立即发布）
    ↓
通过 Creator API 发布到小红书
```

### 任务监控

- 查看 `total_published`：累计发布数量
- 查看 `last_run_at` / `next_run_at`：上次/下次执行时间
- 暂停任务：将状态改为 `paused`

> 自动调度需要开启调度器（`scheduler.enabled: true`）并重启服务。

## 10. 常见问题

### Q：Cookie 怎么获取？

打开浏览器，登录小红书后：
1. 按 `F12` 打开开发者工具
2. 切换到 `Network` 标签
3. 刷新页面，点击任意请求
4. 在 `Request Headers` 中找到 `cookie` 字段
5. 复制完整值粘贴到导入框

### Q：AI 改写没有反应？

检查以下几点：
1. 「模型配置」中是否已添加文本模型并设为默认
2. 点击「测试连接」确认 API Key 和 Base URL 正确
3. 查看浏览器控制台或后端日志是否有报错

### Q：发布失败提示 Cookie 无效？

Creator 账号 Cookie 有时效性，需要重新导入：
1. 账号矩阵 → 找到对应 Creator 账号 → 「删除」
2. 重新从浏览器获取最新 Cookie
3. 重新导入

### Q：定时发布没有自动触发？

确认 `config/default.yaml` 中 `scheduler.enabled: true`，并重启服务：
```bash
python main.py --with-frontend
```

### Q：如何备份数据？

数据库文件位于 `data/spider_xhs.db`，直接复制该文件即可备份。

### Q：如何重置管理员密码？

目前需要直接操作数据库：
```bash
python -c "
from backend.app.core.database import SessionLocal, init_db
from backend.app.core.security import hash_password
from backend.app.models import User
init_db()
db = SessionLocal()
user = db.query(User).filter(User.username == '你的用户名').first()
user.password_hash = hash_password('新密码')
db.commit()
print('密码已重置')
"
```

## 附录：配置参考

### config/default.yaml 关键配置

```yaml
server:
  host: "0.0.0.0"      # 监听地址，0.0.0.0 允许外网访问
  port: 8000

database:
  type: "sqlite"         # sqlite 或 mysql
  sqlite_path: "./data/spider_xhs.db"

security:
  secret_key: "change-me"   # 生产环境必须修改！

scheduler:
  enabled: false         # 开启后支持定时发布和自动运营调度
  interval_seconds: 60   # 调度检查间隔

frontend:
  serve_static: false    # Docker/生产模式设为 true
```

### 环境变量覆盖

```bash
SECRET_KEY=your-secret-key
DATABASE_TYPE=sqlite
SCHEDULER_ENABLED=true
```
