1 快速启动

本地开发模式

pip install -r requirements.txt
cd frontend && npm install && cd ..
python main.py --with-frontend

启动后访问：

  • 前端：http://127.0.0.1:5173
  • API 文档：http://127.0.0.1:8000/docs

Docker 模式

docker-compose up -d

2 注册与登录

首次使用

  1. 打开 http://127.0.0.1:5173
  2. 点击「免费注册」→ 填写用户名（≥3位）和密码（≥6位）
  3. 注册成功后自动进入工作台

提升为管理员

python -m backend.app.core.init_admin

登录说明

  • JWT Token 鉴权，有效期内无需重复登录
  • 支持 Token 刷新，长时间使用不会强制退出

3 模型配置（AI 功能前置）

所有 AI 功能（改写、润色、图片生成）都依赖此配置，请优先完成。

配置步骤

  1. 左侧菜单「设置」→ 点击「模型配置」
  2. 点击「新增配置」，填写以下字段：
字段说明示例
名称自定义标识我的默认文本模型
类型text / imagetext
模型名称具体模型 IDdoubao-pro-32k
Base URLAPI 端点https://ark.cn-beijing.volces.com/api/v3
API Key服务商密钥sk-xxxx
  1. 勾选「设为该类型默认模型」
  2. 点击「保存配置」
  3. 在配置卡片上点击「检查」验证连接

支持的服务商

任何兼容 OpenAI 接口的服务：火山引擎（豆包）、阿里云百炼、DeepSeek、OpenAI、本地 Ollama 等。

4 账号矩阵

管理小红书账号，支持 PC 端（搜索/采集）和 Creator 创作者平台（发布）两种类型。

Cookie 导入（推荐）

  1. 左侧菜单「设置」→ 点击「账号矩阵」→ 「添加账号」
  2. 选择「PC 端账号」或「Creator 账号」→ 选择「Cookie」
  3. 粘贴 Cookie 字符串
  4. 勾选「登录 PC 后同步 Creator 账号」可一次导入两个

如何获取 Cookie

浏览器打开小红书并登录 → F12 → Network → 任意请求 → Request Headers → 复制 cookie 字段值

账号状态

状态含义
active正常可用（系统每 2h 自动巡检）
expiredCookie 已过期，需重新导入
checking正在检测中

5 笔记发现

搜索小红书全站笔记，一键保存到内容库。

关键词搜索

  1. 左侧菜单「内容创作」→「笔记发现」
  2. 选择一个有效的 PC 账号
  3. 输入关键词，设置排序/类型/时间筛选
  4. 点击搜索

查看与入库

点击笔记卡片 → 右侧抽屉展示无水印原图、互动数据、评论 → 点击「保存到内容库」

URL 直查

在输入框粘贴小红书笔记链接 → 点击「URL 直查」

6 内容库

所有采集的笔记统一管理，与小红书账号解耦。

视图切换

  • 卡片视图：图文预览，适合浏览
  • 表格视图：紧凑展示，适合批量操作

筛选与搜索

关键词搜索 / 标签筛选 / 有素材 / 有评论

标签管理

选中笔记 →「编辑标签」→ 输入标签名 → 可在筛选栏复用

批量操作

批量打标签 / 批量导出 JSON/CSV / 批量删除

创建草稿

点击笔记「创建草稿」→ 标题+正文+图片深拷贝到草稿工坊

7 草稿工坊

三栏布局：草稿列表 | 编辑器 | AI 助手

编辑内容

  • 修改标题 / 编辑正文 / 管理标签
  • 拖拽排序图片素材

AI 改写

右侧 AI 助手面板：

  • 改写正文：调用默认文本模型重写正文
  • 润色标题：生成更吸引人的标题

编辑完成 →「发送到发布中心」→ 选择 Creator 账号 / 发布模式 / 可见性 / 话题标签

10 常见问题

Q：Cookie 怎么获取？

  1. 打开浏览器，登录小红书
  2. 按 F12 → Network 标签
  3. 刷新页面，点击任意请求
  4. 在 Request Headers 中找到 cookie 字段，完整复制

Q：AI 改写没有反应？

  • 检查是否已添加文本模型并设为默认
  • 点击「检查」确认 API Key 和 Base URL 正确
  • 查看浏览器控制台或后端日志

Q：发布失败提示 Cookie 无效？

Creator 账号 Cookie 有时效性 → 账号矩阵中删除旧账号 → 重新获取 Cookie 导入

Q：定时发布没有自动触发？

# config/default.yaml 中
scheduler:
  enabled: true        # 确保为 true

Q：如何备份数据？

复制 data/spider_xhs.db 文件即可。

Q：如何重置密码？

python -c "
from backend.app.core.database import SessionLocal, init_db
from backend.app.core.security import hash_password
from backend.app.models import User
init_db()
db = SessionLocal()
user = db.query(User).filter(User.username == '你的用户名').first()
user.password_hash = hash_password('新密码')
db.commit()
print('密码已重置')
"
